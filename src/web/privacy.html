Privacy

This page is about the GizeCat web app (in a browser, or added to the Home Screen of an iPad or an Android tablet) and the GizeCat Android app. In short: your cat stays on your device, and nothing is sent anywhere.

What is kept, and where

  • Your cat and its settings (its name, look, personality, what it has learned and the choices you make in Settings) are kept on this device only: in the browser's local storage for the web app, and in the app's private storage for the Android app.
  • The app's own files are kept in the browser's offline cache by the web app, so that it can start without a connection. They are the same for everyone and hold nothing about you or your cat. The Android app has these files inside the app, so it keeps no such copy.

GizeCat keeps nothing else. What it keeps stays until you delete it, but a browser can also clear it by itself: Safari may do so after 7 days without a visit to a Safari tab, and a browser may do so when space runs low. An app on an iPad's Home Screen has its own storage.

What is sent

Nothing about you or your cat is sent anywhere. There are no accounts, no ads, no analytics and no telemetry. GizeCat never listens to your keyboard and never sees your screen.

  • The web app makes no network requests beyond fetching its own files from the site that hosts it: when you open it, once per version for the offline copy, and the browser's own update checks. The page itself cannot make network requests. The site's server can see those requests for files and may log them, as with any website; they carry nothing from your cat.
  • The Android app has no internet permission, so Android itself blocks its network access. It loads only its own files, from inside the app, and it turns off the system's usage reports for its web view. Its data is not part of any cloud backup. On Android 12 and later, moving to a new device with Android's own device-to-device transfer may bring the cat along.

If the web app is hosted at an address it shares with other sites, such as a GitHub project site, the browser's storage on that address is shared with them too.

Permissions

In a browser or as an installed web app, GizeCat requests no permissions: no camera, no microphone, no location and no notifications. Its sounds are made on the device. The Android app never uses the camera, the microphone or your location either.

The Android app asks only for what the optional floating cat needs, and only when you start it: Android's "Display over other apps" (you turn it on yourself, in Android's own settings page), a foreground service that keeps the cat on screen, and, on Android 13 and later, permission to show that service's small notification. The floating cat only draws the cat. It does not read, capture or record what is on your screen, does not look at other apps and uses no network. Without these permissions the cat lives inside the app, as before. The Android app refuses any permission a web page could ask for.

The one thing the installed web app asks is for the browser to keep its storage instead of clearing it. The browser decides by itself, and this gives GizeCat access to nothing else.

Saving your cat to a file

A profile file is created only when you ask for one, with Save my cat to a file in Settings, and it goes only where you put it. GizeCat reads a file only when you choose one with Load a cat from a file. Nothing is uploaded.

The file holds your cat's name, identity and birth time, its personality, its look, and its behaviour, handling and sound preferences. What it has learned (counters, learned habits and bond) is included only if you tick that option.

A profile file never contains API keys; screen-analysis, AI or consent settings; exclusion lists; window titles, display ids, screen positions or favourite spots; folder paths; startup or shortcut settings; diagnostics; or moods and recent memories.

It is plain, unencrypted text: anyone who has the file can read your cat's name and settings.

Deleting everything

  • Start over: in Settings, under Start again, Start over with a new cat deletes your cat and its settings from this device, and a new cat arrives.
  • An app on an iPad's Home Screen: remove it from the Home Screen, and its storage goes with it.
  • A browser tab, or an app installed from the browser: uninstall the app if there is one, and clear this site's data in the browser's settings, which also removes the offline copy. Uninstalling alone may leave the data in the browser.
  • The Android app: uninstall it, or clear its data in Android's app settings. If Android offers to keep the app's data when you uninstall, do not keep it.
  • A file you saved is yours: delete it wherever you put it. GizeCat does not know where it is.
