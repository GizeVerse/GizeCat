GizeCat was started with --no-sandbox, which turns off the protection that keeps its windows isolated from your system. It does not run that way. On Linux this usually means the system blocks the Chromium sandbox for this package (for example an AppImage on Ubuntu 24.04 or later); install a package that supports the sandbox instead.
